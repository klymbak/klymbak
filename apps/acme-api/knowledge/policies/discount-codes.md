# Discount codes and goodwill

## Live codes

| Code | Discount | Who it's for |
| --- | --- | --- |
| WELCOME10 | 10% | First orders |
| TRAIL15 | 15% | The autumn trail campaign, limited to 500 uses |
| VIP20 | 20% | VIP customers, by invitation |

SUMMER25 has expired. Codes can't be combined, and they don't apply to gift cards.

## When a code doesn't work

1. Check whether the code expired or reached its limit. TRAIL15 has reached its 500 uses.
2. If it ran out, apologise and offer WELCOME10 instead, or VIP20 for VIP customers. When the order is already placed, refund the difference rather than asking the customer to order again.
3. If the code should work, check the order for items it excludes (gift cards).

## Goodwill

Staff can offer goodwill without asking: a 10% code for a late delivery, free express shipping on the next order, or a refund of the shipping cost. Anything more, such as a free product, needs an admin.
